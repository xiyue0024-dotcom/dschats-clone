常见问题

你可能想知道。

会立即替我发送消息吗？
不会。连接账号、保存资料和发布配置都不会直接开启自动发送。你需要为每个联系人选择回复方式（关闭 / AI 草稿 / 自动发送），也可以随时亲自接手。全局默认处于暂停状态。
能同时用两种助手吗？
可以为不同账号选择不同助手。每个账号首次确认一种助手，之后不能更改类型；不同账号的资料与记忆独立管理。
流程助手会替我核实业务结果吗？
不会。它会区分「对方说已完成」和「已由你核实」两种状态。需要核实的关键进展会交给你，不会仅凭一句回复就认定业务完成。
我的聊天记录会被怎么处理？
演示版把数据保存在本地 JSON 文件中，不会上传到任何第三方。正式产品需要明确数据存储位置、留存期限与跨境处理方式，并提供导出与删除能力。
需要付费吗？有套餐限制吗？
不需要。本复刻版已移除套餐与付费墙，注册后即可使用全部功能，也不限制账号数量。大模型 Key 由你自己提供：登录后在「设置 → AI 模型」里填写，费用直接由模型服务商按你的用量收取，平台不经手。不填也能用内置规则引擎。
我的 API Key 安全吗？
Key 用 AES-256-GCM 加密后存在服务器的 data/db.json，加密主密钥是服务器本地生成的 data/.secret。接口只返回掩码（如 gsk_••••••••OfH2），明文永远不会回传到浏览器，也不会出现在任何部署文件里。你可以随时在设置里覆盖或清除。
这是官方产品吗？
不是。这是依据 dschats.com 公开功能整理的复刻演示，用于功能验证与二次开发，与官方无关联。
